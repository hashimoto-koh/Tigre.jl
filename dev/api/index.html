API Reference

This page provides the complete, categorized reference of types, operators, reconstruction algorithms, and utilities in Tigre.jl.

Each item is documented below with its signatures, parameters, mathematical formulation, and usage examples.

Geometry & Coordinate Transformations

Tigre.Geometry — Type
Geometry

CT acquisition geometry specification for 2D/3D cone-beam and parallel-beam CT.

Fields

  • mode::Symbol: Beam geometry mode (:cone or :parallel).
  • nVoxel::NTuple{3, Int}: Number of voxels (nx, ny, nz).
  • sVoxel::NTuple{3, Float32}: Physical volume size (sx, sy, sz) in mm.
  • dVoxel::NTuple{3, Float32}: Voxel pitch (dx, dy, dz) in mm.
  • nDetector::NTuple{2, Int}: Number of detector channels (nu, nv).
  • sDetector::NTuple{2, Float32}: Physical detector size (su, sv) in mm.
  • dDetector::NTuple{2, Float32}: Detector pixel pitch (du, dv) in mm.
  • angles::Matrix{Float32}: Gantry projection angles of size 3 × nangles (radians).
  • DSD::Vector{Float32}: Source-to-Detector distance in mm per projection.
  • DSO::Vector{Float32}: Source-to-Origin distance in mm per projection.
  • offOriginX::Vector{Float32}, offOriginY::Vector{Float32}, offOriginZ::Vector{Float32}: Object offset in mm.
  • offDetectorU::Vector{Float32}, offDetectorV::Vector{Float32}: Detector panel lateral/vertical offset in mm.
  • rotDetectorRoll::Vector{Float32}, rotDetectorPitch::Vector{Float32}, rotDetectorYaw::Vector{Float32}: Detector Euler angles (radians).
  • COR::Vector{Float32}: Centre-of-rotation offset in mm per projection.
  • accuracy::Float32: Interpolation accuracy parameter for ray-tracing kernels.

Tigre.Ax — Function
Ax(volume::AbstractArray{Float32, 3}, geo::Geometry; projection_type = :siddon, gpu_ids = nothing) -> Array{Float32, 3}

Compute X-ray forward projection (Radon transform) p = A x using GPU CUDA kernels.

Arguments

  • volume::AbstractArray{Float32, 3}: 3D voxel array of size (nx, ny, nz).
  • geo::Geometry: CT acquisition geometry specification (Geometry).

Keyword Arguments

Returns

  • 3D projection tensor Array{Float32, 3} of size (nu, nv, nangles).

Examples

proj = Ax(phantom, geo; projection_type=:siddon)

See also: Ax!, Atb.

Analytical Reconstruction

Tigre.fdk — Function
fdk(projection::StridedArray{Float32, 3}, geo::Geometry; filter = :ram_lak, parker = false, gpu_ids = nothing) -> volume

Feldkamp-Davis-Kress (FDK) cone-beam filtered backprojection reconstruction.

Reconstructs a 3D attenuation volume from cone-beam projection data using distance-weighted filtering followed by cone-beam backprojection. Supports offset-detector acquisitions (automatic Wang weighting) and short scans (Parker redundancy weighting).

Arguments

  • projection::StridedArray{Float32, 3}: Input projection array of size (nu, nv, nangles).
  • geo::Geometry: Cone-beam acquisition Geometry (geo.mode === :cone).

Keyword Arguments

  • filter::Symbol = :ram_lak: Ramp filter window (:ram_lak, :shepp_logan, :cosine, :hamming, or :hann) (default: :ram_lak).
  • parker::Bool = false: Apply Parker redundancy weighting for short scans (default: false).
  • gpu_ids = nothing: Zero-based GPU device ID(s) to execute on, or nothing for default device (default: nothing).

Returns

  • Reconstructed 3D volume Array{Float32, 3} of size (geo.nVoxel[1], geo.nVoxel[2], geo.nVoxel[3]).

Examples

recon = fdk(proj, geo; filter=:ram_lak)

Reference

  • Feldkamp, L. A., Davis, L. C., & Kress, J. W., "Practical cone-beam algorithm", JOSA A, 1(6), 1984.

Tigre.wang_padding — Function
wang_padding(projection::StridedArray{Float32, 3}, geo::Geometry) -> Tuple{Array{Float32, 3}, Geometry, Vector{Float32}}

Pad projection data along the detector lateral (u) axis and update geometry for offset-detector (displaced detector) CT.

Arguments

  • projection::StridedArray{Float32, 3}: Projection data array (nu, nv, nangles).
  • geo::Geometry: CT geometry specification with non-zero detector offset (geo.offDetectorU).

Returns

  • A tuple (padded_projection, padded_geometry, theta_redundancy_angles) where:
    • padded_projection: Array with detector column dimension symmetrically padded.
    • padded_geometry: Geometry updated with expanded detector width and centered offsets.
    • theta_redundancy_angles: Per-projection overlap angular ranges (radians) for subsequent wang_preweight!.

Examples

padded_proj, padded_geo, theta = wang_padding(proj, geo)

Algebraic & POCS Solvers

SART & SIRT Family

Tigre.sart — Function
sart(projection::AbstractArray{Float32, 3}, geo::Geometry, niter::Integer; init = :zeros, lambda::Real = 1f0, lambda_red::Real = 1f0, order_strategy = :ordered, nonneg::Bool = true, gpu_ids = nothing, projection_type = :siddon, backprojection_type = :fdk, compute_l2::Bool = false, stop_on_l2_increase::Bool = false, residual_projection_type = :siddon, return_history::Bool = false, show_progress::Bool = false, plan = nothing) -> volume

Simultaneous Algebraic Reconstruction Technique (SART). Equivalent to ossart with blocksize = 1.

Iteratively updates the 3D volume by backprojecting projection residuals one projection angle at a time.

Arguments

  • projection::AbstractArray{Float32, 3}: 3D projection data array (nu, nv, nangles).
  • geo::Geometry: CT acquisition geometry specification.
  • niter::Integer: Number of complete iterations over all angles.
  • init = :zeros: Initial volume guess (:zeros, :fdk, or custom 3D array, default: :zeros).
  • lambda::Real = 1.0f0: Initial relaxation parameter (default: 1.0f0).
  • lambda_red::Real = 1.0f0: Relaxation factor reduction per iteration (default: 1.0f0).
  • order_strategy = :ordered: Projection angle visiting order (:ordered or :random, default: :ordered).
  • nonneg::Bool = true: Enforce non-negativity constraint volume >= 0 (default: true).
  • gpu_ids = nothing: Zero-based GPU device ID(s) or nothing for default device (default: nothing).
  • projection_type = :siddon: Forward projection ray-tracing kernel (:siddon or :interpolated, default: :siddon).
  • backprojection_type = :fdk: Backprojection interpolation kernel (:fdk or :voxel_ray, default: :fdk).
  • compute_l2::Bool = false: Compute residual L2 norm per iteration (default: false).
  • stop_on_l2_increase::Bool = false: Terminate iterations early if residual L2 norm increases (default: false).
  • residual_projection_type = :siddon: Ray-tracing kernel for residual evaluation (default: :siddon).
  • return_history::Bool = false: Return (volume, history::IterativeHistory) when true (default: false).
  • show_progress::Bool = false: Display interactive progress bar (default: false).
  • plan = nothing: Optional precomputed ARTPlan for zero-allocation reuse (default: nothing).

Returns

  • Array{Float32, 3}: Reconstructed 3D volume (or tuple (volume, history::IterativeHistory) if return_history = true).

Examples

geo = default_geometry()
proj = Ax(phantom, geo)
vol = sart(proj, geo, 10)

3D Total Variation (TV) proximal denoising via GPU Chambolle/Fast Gradient Projection (FGP) algorithm matching upstream TIGRE im3DDenoise.

Following upstream TIGRE convention, the input volume is min-max normalized to $[0, 1]$ before invoking the CUDA proximal solver, and scaled back to its original intensity range afterward:

\[\min_{u \in [0, 1]} \frac{\lambda}{2} \|u - \tilde{f}\|_2^2 + \mathrm{TV}(u)\]

where $\tilde{f} = (f - \min f) / (\max f - \min f)$ and $\lambda$ is the fidelity weight parameter (lambda). Smaller values of lambda impose stronger TV regularization (more smoothing), while larger values preserve closer fidelity to the original volume.

Arguments

  • volume::AbstractArray{Float32, 3}: Input noisy 3D image (nx, ny, nz).

Keyword Arguments

  • lambda::Real = 15f0: TV fidelity parameter on $[0, 1]$-normalized intensity (default: 15f0). Lower values produce stronger TV smoothing.
  • spacing = (1f0, 1f0, 1f0): Physical voxel pitch (dx, dy, dz) in mm (default: (1f0, 1f0, 1f0)).
  • maxiter::Integer = 100: Number of dual gradient ascent iterations (default: 100).
  • gpu_ids = nothing: Zero-based GPU device ID(s) or nothing for default device (default: nothing).

Returns

  • Denoised 3D volume Array{Float32, 3} of the same dimensions as volume.
